# *Junior Growth Marketing Specialist Project*

To complete the tasks assigned in the project focused on creating a GitHub repository, I followed the steps outlined below:

## Step 1 📥

The first step was downloading and installing Cursor. The process was straightforward, as I only needed to visit the official website and complete the installation. I did not encounter any difficulties during this stage.

## Step 2 🤔

The second task involved installing the Claude Code extension within Cursor. This was the most challenging part of the process because I initially could not locate the extensions section. To solve this issue, I searched for a YouTube tutorial that guided me through the setup. Although my interface looked slightly different from the one shown in the video, after several attempts I found a link labeled "Window Editor" in the upper-right corner. Once I accessed that section, I was able to locate the extensions icon and use the search bar to install Claude Code successfully.

## Step 3 ✍️

After discovering where the extensions were located, installing the next required extension, Codex, became a much simpler and faster process.

## Step 4 💻

Once I completed the tasks related to Cursor, I proceeded to create a GitHub account. I accessed the platform through my web browser, completed the registration process, and logged into both the application and the web version.

## Step 5 👌

Within GitHub, I was able to quickly identify the "Create Repository" option. I configured the required settings, including initializing the repository with a README.md file and selecting the option to make the repository public.

Throughout this process, I found the platform's interface to be user-friendly and intuitive, which made it easier to complete the required tasks efficiently.

## Step 6 🎓

Finally, I accessed the newly created repository to document my experience using these tools. This activity helped me better understand the usefulness of GitHub, Cursor, and their extensions, while also allowing me to keep an organized record of the entire process.
